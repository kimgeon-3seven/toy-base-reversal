# 007 · 공격 유닛의 그리드 되감기 수정

## 목표

- 플레이어 공격 라운드에서 유닛이 방어벽 또는 코어를 공격할 때 이전
  그리드로 되돌아가는 현상을 제거한다.
- 이동과 공격의 전환을 그리드 규칙에 맞게 안정화하고, 집중 공격으로
  목표가 바뀌어도 같은 문제가 재발하지 않게 한다.

## 재현과 원인

`AttackUnit`은 확정된 `currentPosition`과 다음 그리드 `nextPosition`
사이를 `movementProgress`로 보간한다. 기존 `AttackCombat`은 보간된 화면
좌표가 공격 사거리에 들어오는 즉시 `cancelMovement()`를 호출했다.

`cancelMovement()`는 다음 위치와 이동 진행도를 모두 초기화하므로 화면상
그리드 사이까지 이동한 유닛이 마지막으로 확정된 이전 그리드 좌표로
되감겼다. 방어벽, 타워, 코어, 집중 공격이 같은 이동 취소 방식에 영향을
받았다.

## 수정 설계

1. `AttackUnit.continueActiveMovement()`가 현재 진행 중인 한 칸 이동을
   저장된 목표와 속도로 끝까지 책임지도록 이동 상태를 캡슐화했다.
2. `AttackCombat`은 표적 탐색과 공격 판정보다 활성 이동을 먼저 처리한다.
3. 한 칸 이동 중 목표가 바뀌어도 현재 그리드 중심까지 도착한 다음 새
   경로 또는 공격을 선택한다.
4. 공격을 시작한 유닛은 확정된 그리드에 고정되므로 공격 쿨다운 동안
   좌표가 흔들리거나 뒤로 이동하지 않는다.

## 자동 회귀 테스트

- 방어벽이 이동 중 사거리에 들어와도 화면 X 좌표가 감소하지 않음
- 코어가 이동 중 사거리에 들어와도 그리드 이동을 완료한 뒤 피해 적용
- 집중 공격이 이동 도중 발령되어도 기존 한 칸 이동을 완료
- 방어벽·코어 공격 중 확정된 그리드 좌표 유지
- `AttackUnit`이 새 길찾기 결과 없이 저장된 이동 목표를 완료

되감기 수정으로 유닛이 타워 옆에 정상 정착하면서 기존 교란 테스트에서
타워가 검증 도중 먼저 파괴되는 결합 문제가 드러났다. 해당 타워 체력을
높여 교란 쿨다운만 독립적으로 검증하도록 테스트 책임을 분리했다.
