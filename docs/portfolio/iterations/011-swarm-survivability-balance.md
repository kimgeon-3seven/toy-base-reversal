# 011 · 태엽 군단 생존력과 역할 밸런스

## 목표

- 공격 편성에서 방패병만 고르는 현상을 줄인다.
- 태엽 군단의 `저비용·고화력 물량` 역할을 살리되 박격포 상성은 유지한다.
- 감각적인 수치 변경을 같은 코스트 기준의 자동 테스트로 재현 가능하게 기록한다.

## 문제

공격 태엽 군단은 2포인트에 체력 38, 방패병은 4포인트에 체력 125였다.
같은 4포인트를 사용하면 태엽 군단 2기의 합산 체력은 76으로 방패병보다 39% 낮았다.
포인트당 공격력은 높지만 진입로 동시 출격 제한과 0.9초의 후속 출격 간격 때문에
물량이 형성되기 전에 각개격파되기 쉬웠다. 박격포의 1.65배 범위 피해까지 겹치면서
관통포를 상대하는 본래 역할도 체감하기 어려웠다.

## 수정 설계

1. 플레이어 공격 태엽 군단의 체력만 38에서 50으로 높였다.
2. 가격 2, 공격력 8, 공격 주기 440ms, 이동 속도 2.05는 유지했다.
3. 방어 라운드 NPC 태엽 군단 수치는 변경하지 않아 방어 난이도는 보존했다.
4. 같은 4포인트의 합산 체력은 76에서 100으로 증가하지만 방패병의 125보다는 낮다.
5. 태엽 군단의 포인트당 DPS는 방패병보다 높게 유지해 `공격`, `탱킹` 역할을 분리했다.
6. 박격포의 상성 피해로는 여전히 2발에 쓰러지도록 하드 카운터를 유지했다.

## 자동 회귀 기준

- 같은 4포인트 태엽 군단의 합산 체력은 방패병의 80% 이상, 100% 미만
- 팝건 기준 태엽 군단 2기는 총 14발, 방패병은 16발에 처치
- 박격포 상성 공격 기준 태엽 군단 1기는 2발에 처치
- 관통포 기준 태엽 군단 2기는 총 4발, 상성 피해를 받는 방패병은 3발에 처치
- 일반 모드 1~5라운드 기준 편성의 방어·공격 성공과 목표 시간 범위 유지

## QA

- 신규 역할·상성 테스트 4개 통과
- 전체 56개 테스트 파일의 182개 테스트 통과
- ESLint, TypeScript, GitHub Pages·itch.io 프로덕션 빌드 통과
- 로컬 브라우저에서 첫 방어, 역할 반전, 공격 준비와 공격 전투 진입 확인
- 브라우저 콘솔 경고·오류 0건 확인

## 포트폴리오 포인트

플레이 감상인 `몸이 너무 약하다`를 단순 체력 상향으로 끝내지 않고 같은 코스트의
생존 시간, 포인트당 화력, 하드 카운터 처치 횟수로 분해했다. 플레이어와 NPC 설정이
분리된 구조를 활용해 공격 선택지만 개선하고 기존 방어 난이도와 상성 구조는 보존했다.
