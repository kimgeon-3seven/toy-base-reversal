# 006 · 고무줄 사수 8방향 애니메이션과 코어 제자리 공격 수정

## 목표

- 정적 원화로만 표시되던 `고무줄 사수`를 실제로 걷고 고무줄을 당겨
  발사하는 장난감 유닛으로 완성한다.
- NPC 방어 웨이브와 플레이어 공격 부대가 같은 방향별 애니메이션을
  공유하게 한다.
- 플레이어 유닛과 코어 중심이 겹치면 피해만 적용되고 제자리 공격
  애니메이션은 재생되지 않던 회귀를 수정한다.

## 베이스라인과 원인

- `ranger`는 `unit-ranger-v2.png` 한 장을 방향에 맞춰 회전했다.
- `DirectionalAnimationCatalog`에는 방패병과 태엽 군단 프로필만 있었다.
- `BattlefieldSpriteView.playAttackToward()`는 공격 대상과 유닛의 좌표가
  같아 방향 벡터 길이가 0이면 공격 상태를 시작하기 전에 반환했다.
- 공격 도메인의 피해·이벤트는 정상이었지만 표시 계층의 애니메이션만
  누락됐다.

## 이미지 제작 과정

Built-in ImageGen을 사용하고 `unit-ranger-v2.png`를 캐릭터 정체성 기준
이미지로 제공했다. 첫 투명 배경 요청은 실제 알파 대신 체크무늬가 픽셀로
생성되어 폐기했다. 이후 생성 원본에는 단색 `#FF00FF` 크로마 배경을 쓰고,
결정론적 합성기가 이를 투명 알파로 변환했다.

직접 제작한 방향은 `N, NE, E, SE, S`의 5개다. 게임에서 드물게 발생하는
왼쪽 이동·공격은 새 원본을 생성하지 않고 각 프레임을 수평 반전해 만들었다.

- `NE → NW`
- `E → W`
- `SE → SW`

공통 프롬프트 규격:

- 위 행 4프레임: `contact → passing → opposite contact → passing`
- 아래 행 4프레임: `ready → rubber-band pull → release → recover`
- 고정 요소: 크림·갈색 플라스틱, 깃털 탐험가 모자, 등에 꽂힌 튜브,
  나무 Y자 고무줄총과 노란 고무줄
- 고정 축: 동일한 캐릭터 크기·몸 중심·발 기준선
- 금지 요소: 공격 중 위치 이동, 방향 변경, 장비 누락·복제, 화살·총기,
  그림자, 텍스트, 워터마크

최종 결과:

- `unit-ranger-walk-8way-v1.png`: 640×1280, 투명 ARGB, 32프레임
- `unit-ranger-attack-8way-v1.png`: 640×1280, 투명 ARGB, 32프레임
- 64개 프레임 모두 비어 있지 않음을 픽셀 검사로 확인
- 생성 원본 5개는 Git에서 제외되는 `work/imagegen/ranger-directional-v1`에
  보관하고 게임이 사용하는 최종 시트만 저장소에 포함한다.

## 코드 구조 변경

1. `build-directional-sprite-sheets.ps1`에 `MirrorLeftDirections` 옵션을
   추가했다. 시트 전체가 아니라 잘라낸 각 셀을 반전하므로 공격 프레임의
   시간 순서는 역전되지 않는다.
2. 고무줄 사수 걷기·공격 시트를 Phaser spritesheet로 사전 로드한다.
3. `DirectionalAnimationCatalog`의 아키타입 프로필 레지스트리에
   `ranger`를 추가해 NPC와 플레이어가 같은 자산을 사용한다.
4. `SpriteAttackFeedbackResolver`가 방향·반동 계산만 담당한다. 목표가
   겹치면 현재 방향을 유지하고 반동은 0으로 반환한다.
5. `BattlefieldSpriteView`는 방향 벡터가 0이어도 공격 상태부터 시작한다.
   따라서 코어 위에 정지한 유닛도 제자리 발사 애니메이션을 재생한다.

- ESLint, TypeScript, Vite 프로덕션 빌드 통과
- Vitest: 51개 파일, 160개 테스트 통과
- 새 렌더러 회귀 테스트: `유닛 위치 = 코어 위치`에서
  `ranger-attack-east` 재생 확인
- 이미지 검사: 걷기·공격 시트 각 640×1280, 32프레임, 빈 프레임 0개
- 브라우저 3라운드 방어: 붉은 받침 NPC 고무줄 사수의 방향별 보행 확인
- 브라우저 3라운드 공격: 청록 받침 플레이어 고무줄 사수의 생성과
  타워 접근·공격 확인
- 브라우저 콘솔 오류·경고 0건
- 기존 방패병·태엽 군단 프로필 자동 테스트 회귀 없음

브라우저 공격 QA의 추천 편성은 보강된 방어선에 전멸했으므로 코어 중첩
경계는 반복 플레이 대신 실제 렌더러 통합 테스트로 고정했다.
