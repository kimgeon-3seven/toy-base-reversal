# 009 · 첫 1분 온보딩 라운드

## 목표

- 처음 플레이하는 사람이 복잡한 설계 기능보다 `막고 나서 내가 뚫는다`는
  핵심 역할 반전을 먼저 경험하게 한다.
- 첫 라운드만 쉽게 만들고 2라운드부터 기존 전략 깊이와 난이도를 복원한다.

## 문제

기존 첫 라운드는 30초 준비, 9기의 적, 강화·설계 저장·이력 기능을 한 번에
제공했다. 아직 핵심 재미를 보지 못한 플레이어가 여러 버튼과 좁은 방어 성공
조건을 먼저 학습해야 했고, 역할 반전에 도달하기 전에 이탈할 가능성이 컸다.

## 수정 설계

1. `RoundOnboardingPolicy`가 현재 라운드에 맞는 준비시간, 웨이브 묶음 수,
   출현 간격, 고급 편집 허용 여부와 추천 배치 칸을 제공한다.
2. 첫 일반 라운드는 완성된 초기 방어선과 건설 부품 4를 유지하면서 준비시간을
   12초, 적을 6기로 줄인다.
3. 하단에는 팝건·블록 벽·방어 시작만 표시하고, 빛나는 두 칸으로 첫 배치를
   안내한다.
4. 강화·실행 취소·다시 실행·저장·되돌리기는 2라운드부터 다시 표시한다.
5. 챌린지 모드와 2라운드 이후는 기존 30초 준비와 전체 시스템을 그대로 쓴다.

## QA

- 정책 단위 테스트로 첫 라운드 한정 적용과 2라운드·챌린지 복원을 검증한다.
- 고정 시뮬레이션으로 초기 설계가 첫 웨이브를 안정적으로 방어하는지 확인한다.
- 브라우저에서 12초 준비, 6기 웨이브, 추천 칸, 축소된 설계 패널을 확인한다.
- 첫 방어 결과는 코어 120/120, 처치 6, 누수 0이며 콘솔 오류는 0건이었다.
- 시작부터 역할 반전과 공격 준비 진입까지 1분 이내임을 확인했다.
- 첫 공격 돌파 후 2라운드에서 30초 준비, 18기의 적, 박격포와 전체 설계
  기능이 복원되는 것을 확인했다.
- ESLint, TypeScript, 53개 테스트 파일의 172개 테스트와 GitHub Pages·itch.io
  프로덕션 빌드가 통과했다.

## 포트폴리오 포인트

난이도를 전체적으로 낮추지 않고 최초 라운드에만 별도 정책을 적용했다.
도메인 설정과 화면 표시가 같은 정책을 참조하므로 이후 온보딩 수치를 조정해도
전투 규칙과 UI가 어긋나지 않으며, 2라운드부터 게임의 전략적 깊이를 보존한다.
