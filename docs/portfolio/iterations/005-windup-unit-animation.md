# 005 · 태엽 군단 8방향 보행·공격 애니메이션

## 목표

- 프로토타입에서 한 방향 정적 이미지였던 `태엽 군단`을 실제로 걷고
  제자리에서 권투 공격하는 장난감 유닛으로 완성한다.
- NPC 방어 웨이브와 플레이어 공격 부대가 동일한 애니메이션 자산과
  상태 전환 규칙을 사용하게 한다.
- 이후 고무줄 사수와 지휘관도 쉽게 추가할 수 있도록 애니메이션 연결부를
  아키타입별 프로필 구조로 확장한다.

## 베이스라인

- `swarm`은 `unit-windup-v2.png` 한 장을 이동 방향에 맞춰 회전했다.
- 걷기·공격 프레임이 없어 이동 중에는 별도 상하 흔들림만 보였다.
- `DirectionalAnimationCatalog`는 `tank` 방패병만 조건문으로 처리했다.

## 이미지 제작 과정

Built-in ImageGen을 사용하고 `unit-windup-v2.png`를 캐릭터 정체성 기준
이미지로 제공했다. 한 장에서 8방향을 동시에 생성해 장비와 방향이 섞이는
위험을 줄이기 위해 방향마다 2행×4열 원본을 별도로 제작했다.

- 방향: `N, NE, E, SE, S, SW, W, NW`
- 상단 4프레임: `contact → passing → opposite contact → passing`
- 하단 4프레임: `guard → punch → recoil → guard`
- 고정 요소: 크림·갈색 플라스틱, 탐정 모자, 갈색 권투장갑·신발,
  등에 연결된 황금색 이중 고리 태엽키
- 배경: 코드에서 투명화할 단색 `#FF00FF`
- 금지 요소: 프레임 사이 방향 변경, 장비 누락·복제, 이동하는 공격 자세,
  그림자, 텍스트, 워터마크

첫 남서 생성본은 실제로 화면 오른쪽을 향해 남동 원본으로 재분류했다.
남서는 코와 펀치가 화면 왼쪽을 향하도록 조건을 강화해 다시 생성했다.
채택한 8개 방향 원본은 결정론적 합성 스크립트가 크로마 배경을 제거하고
모든 프레임을 동일 배율, 수평 중심, 발 기준선에 맞췄다.

최종 결과:

- `unit-windup-walk-8way-v1.png`: 640×1280, 투명 ARGB, 32프레임
- `unit-windup-attack-8way-v1.png`: 640×1280, 투명 ARGB, 32프레임
- 64개 프레임 모두 비어 있지 않음을 픽셀 검사로 확인

## 코드 구조 변경

1. 태엽 군단 걷기·공격 시트를 Phaser spritesheet로 사전 로드한다.
2. `DirectionalAnimationProfile`에 보행 프레임 순서를 포함하고,
   `UNIT_PROFILES` 레지스트리가 `tank`와 `swarm`을 아키타입별로 제공한다.
3. 태엽 군단은 생성된 네 보행 프레임을 모두 사용하는
   `[0, 1, 2, 3]` 주기를 가진다. 기존 방패병 주기는 회귀 방지를 위해
   `[0, 1, 2, 1]`로 유지한다.
4. NPC와 플레이어 렌더러가 같은 `swarm` 프로필을 사용한다. 진영은
   스프라이트 전체 색칠이 아니라 붉은색·청록색 장난감 받침으로 구분한다.
5. 새 아키타입은 프로필을 레지스트리에 추가하는 방식으로 확장할 수 있어
   렌더러의 분기 증가를 줄였다.
