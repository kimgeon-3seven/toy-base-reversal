# 003 · 공격 방패병 애니메이션 연결·연속성 수정

## 발견된 문제

8방향 시트가 배포됐지만 공격 라운드에서 기존 정지 이미지처럼 보였고,
프레임이 전환될 때 캐릭터의 크기와 중심점이 흔들렸다.

## 원인

- 공격 방패병의 애니메이션 프로필을 유닛 종류가 아니라 정적 텍스처 키를
  통해 간접적으로 찾고 있었다.
- 시트 생성기가 프레임마다 가시 영역을 따로 계산한 뒤 개별 확대했다.
  팔다리나 무기가 뻗을 때마다 배율과 중심이 달라졌다.
- 순간 이동량만으로 걷기 상태를 판정해 그리드 경계에서 대기 자세가 잠깐
  끼어들 수 있었다.
- 전체 이미지에 적용한 청록색 틴트가 작은 캐릭터의 관절 동작을 가렸다.

## 수정

1. `DirectionalAnimationCatalog`가 공격 유닛 종류 `tank`를 직접 받아 방패병
   프로필을 반환하도록 변경했다.
2. 걷기 상태에 140ms 유예 시간을 두어 짧은 위치 갱신 간격에서도 동작이
   끊기지 않도록 했다.
3. 현재 애니메이션 키를 추적해 동작이나 방향이 바뀔 때만 Phaser
   애니메이션을 전환하도록 했다.
4. 걷기와 공격의 각 방향별 4프레임이 하나의 공통 가시 영역, 배율, 발
   기준선을 사용하도록 시트 빌더를 수정했다.
5. 공격 방패병의 전체 이미지 틴트를 제거하고 청록색 장난감 발판으로 팀을
   구분했다.
