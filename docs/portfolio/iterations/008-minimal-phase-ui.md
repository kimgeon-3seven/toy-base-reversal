# 008 · 단계별 최소 HUD와 itch.io 조작 안내

## 목표

- 게임 화면은 현재 판단에 필요한 정보만 보여주고 상세 조작은 itch.io
  페이지와 일시정지 메뉴로 옮긴다.
- `설계 → 방어 → 역할 반전 → 공략`이라는 핵심 흐름은 축소하지 않고
  더 빠르게 읽히게 만든다.
- 전략 편성 UI는 유지하되 실제로 조작하는 준비 단계에서만 표시한다.

## 문제

기존 화면은 424px 높이의 우측 임무 카드가 목표, 수치, 선택 정보와
조작법을 동시에 반복했다. 하단 준비 패널도 전투 중 계속 남아 있어 전장과
공격 이펙트보다 설명 UI가 먼저 보였다. 처음 보는 플레이어에게 필요한
정보와 이미 조작을 이해한 플레이어에게 필요한 정보가 구분되지 않았다.

## 참고와 적용 원칙

Parryway의 전투 화면처럼 플레이 중에는 핵심 상태만 유지하는 정보 계층을
참고했다. 다만 Toy Base Reversal은 방어 설계와 공격 편성이 코어 재미이므로
준비 패널을 제거하지 않고 해당 단계에서만 노출했다. 레퍼런스의 시각 자산이나
레이아웃을 복제하지 않고 단계별 정보 밀도 원칙만 적용했다.

## 수정 설계

1. `BattlefieldPhaseUiPolicy`가 단계별 임무 카드, 방어 설계, 공격 편성,
   지휘관 능력 카드의 표시 여부와 상태 알림 위치를 결정한다.
2. 상단 진행 표시는 번호와 중복 설명을 제거하고 네 단계와 현재 강조만 남긴다.
3. 우측 임무 카드는 높이를 424px에서 222px로 줄이고 핵심 수치 3개만 표시한다.
4. 방어 설계와 공격 편성은 준비 단계가 끝나면 숨기고, 공격 전투에는 Q/E
   능력 카드만 남긴다.
5. 일시정지에 `조작법`을 추가해 현재 단계에 필요한 키만 보여준다.
6. 일반 상태 알림은 3.6초, 경고는 5초 뒤 자동으로 사라지게 했다.
7. itch.io 게임 하단에 사용할 한 문장 소개, 세 가지 특징과 전체 조작 문안을
   별도 문서로 작성했다.

## QA

- 단계별 UI 정책 단위 테스트 4개 통과
- 방어 준비에서 설계 패널, 방어 전투에서 전장과 핵심 수치만 표시 확인
- 공격 준비에서 편성 패널, 공격 전투에서 Q/E 카드만 표시 확인
- 일시정지의 방어 설계 조작 안내와 뒤로 가기 확인
- 1280×720, 1280×800, 1920×1080 화면에서 잘림 없이 비율 유지 확인
- 브라우저 콘솔 경고·오류 0건

## 포트폴리오 포인트

화면을 단순히 삭제한 작업이 아니라, 게임 단계와 플레이어의 현재 행동을
기준으로 UI 표시 정책을 분리했다. 전략적 선택은 보존하면서 전투 가독성을
높였고, 상세 설명은 배포 페이지와 일시정지라는 적절한 위치로 이동했다.
