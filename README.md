# Toy Base Reversal

장난감 요새를 직접 설계해 적의 웨이브를 막고, 공격 부대를 편성해 자신이 만든 요새를 돌파하는 PC 브라우저 전략 게임입니다.

## 공개 플레이

[GitHub Pages에서 플레이하기](https://kimgeon-3seven.github.io/toy-base-reversal/)

`main` 브랜치에 변경사항이 게시되면 GitHub Actions가 린트, 테스트와 프로덕션 빌드를 통과한 결과물만 자동 배포합니다. 온라인 순위표 연결 전에도 게임과 개인 기록은 로그인 없이 이용할 수 있습니다.

### 웹게임 진입

첫 접속에서는 빈 캔버스 대신 장난감 전쟁 로딩 화면과 이미지·음원 준비 진행률을 표시합니다. 로딩이 끝나도 게임을 자동으로 시작하지 않고 `클릭해서 시작`을 기다리며, 이 첫 입력에서 브라우저 오디오 재생 권한을 활성화합니다. 전체화면 API를 지원하는 브라우저에서는 진입 화면의 `전체화면으로 플레이`와 게임 중 우측 상단 버튼을 사용할 수 있습니다.

게임 화면은 원본 1280×800의 1.6 비율을 유지한 채 브라우저 안에 자동으로 맞춰집니다. 좁은 화면과 터치 중심 기기도 차단하지 않지만, 정밀한 마우스 조작을 위해 PC 브라우저와 가로 화면을 권장합니다. 에셋 로딩에 실패하면 멈춘 화면 대신 네트워크 확인과 다시 불러오기 버튼을 제공합니다.

## 현재 구현된 프로토타입 조작

일반 모드는 총 5라운드이며, 각 라운드는 `방어 준비 → 방어 전투 → 공격 준비 → 공격 전투` 순서로 진행됩니다. 공격에 성공하면 돌파시간이 기록되고 이전 방어 설계를 유지한 채 다음 라운드로 넘어갑니다. 5라운드를 모두 완료하면 챌린지 모드 진입 예고가 표시됩니다.

게임 시작 시 장난감 전쟁의 핵심인 `방어 → 역할 반전 → 내 기지 돌파`를 한 화면으로 소개합니다. 최초 플레이에서는 필요한 규칙을 방어 준비, 방어 전투, 공격 준비, 지휘관 조작 시점에 차례로 안내하며 이후 실행에서는 짧은 시작 화면만 표시합니다. `Esc`로 상세 안내를 건너뛸 수 있고, 방어 준비 중 `H`를 누르면 언제든 첫 안내를 다시 볼 수 있습니다. 시작 화면에는 브라우저에 저장된 개인 최고 기록도 표시됩니다.

전투 중 HUD는 라운드·현재 단계·핵심 목표와 수치만 유지합니다. 방어 설계와 공격 편성 패널은 해당 준비 단계에만 나타나고 전투가 시작되면 자동으로 사라집니다. 전체 조작법은 itch.io 페이지와 `일시정지 → 조작법`에서 현재 단계에 맞춰 확인할 수 있습니다.

방어 결과에서는 처치율과 코어 보존율이 출격 포인트로 바뀌는 과정을 막대로 보여줍니다. 역할 반전 후에는 방금 지킨 동일한 설계의 타워 구성과 현재 사용할 수 있는 상성 유닛을 요약하며, 공격 성공 시 방어 등급·성과와 공략 시간을 한 화면에서 비교합니다. 공격 전투 중에는 집중 공격 대상 파괴와 적 코어 50%·25% 돌파처럼 중요한 전환점만 별도로 알립니다.

화면 위쪽의 `소리 설정`에서 배경음악과 효과음 볼륨을 각각 0~100%로 조절할 수 있고, `M` 키 또는 설정창의 버튼으로 전체 소리를 켜거나 끌 수 있습니다. 볼륨과 음소거 상태는 브라우저에 저장되며, 진입 화면의 첫 클릭으로 브라우저 오디오를 활성화한 뒤 배경음악이 시작됩니다. 장면을 다시 시작해도 배경음악은 한 트랙만 재사용합니다.

준비·전투·역할 반전 중에는 화면 위쪽의 `일시정지` 또는 `Esc`로 게임을 멈출 수 있습니다. 준비시간, 전투 계산, 투사체와 화면 애니메이션, 역할 반전 타이머가 함께 정지합니다. 일시정지 창에서는 현재 단계 조작법을 확인할 수 있으며, `게임 나가기`는 한 번 더 확인한 뒤 현재 도전을 포기하고 시작 화면으로 돌아갑니다. 개인 기록·닉네임·소리 설정은 유지하고, 공격 능력의 대상을 선택하는 중에는 `Esc`가 대상 선택 취소에 우선 사용됩니다.

### 방어 준비 및 전투

- `1`: 팝건 포탑(건설 부품 3) — 고무줄 사수에게 강함
- `2`: 블록 박격포(건설 부품 5) — 태엽 군단에게 강함, 2라운드 해금
- `3`: 태엽 관통포(건설 부품 6) — 방패병에게 강함, 3라운드 해금
- `4`: 블록 벽(건설 부품 2)
- 왼쪽 클릭: 시설 배치 또는 선택, 선택 후 빈 칸 클릭 시 무료 재배치
- 오른쪽 클릭: 시설 판매 및 건설 비용 100% 환급
- `Ctrl+Z` / `Ctrl+Y`: 직전 설계 변경을 한 단계씩 실행 취소 / 다시 실행
- `U`: 선택한 타워를 2레벨로 업그레이드
- `S`: 현재 방어 설계와 건설 부품 잔액을 저장 지점으로 지정
- `R`: 여러 변경을 한꺼번에 버리고 저장 지점의 설계·체력·부품 잔액으로 초기화
- `Space`: 1라운드 12초, 2라운드 이후 30초인 준비 시간을 일찍 종료하고 방어전 시작
- `H`: 첫 플레이 안내 다시 보기

진입점 또는 코어 보호 구역에는 시설을 지을 수 없으며, 세 진입점 중 하나라도 코어까지 갈 수 없게 만드는 배치는 거부됩니다.

일반 모드는 건설 부품 15로 시작하며 초기 팝건 포탑 3기와 블록 벽 1기의 비용 11을 제외한 잔액 4부터 직접 사용할 수 있습니다. 미사용 부품은 전액 이월되고, 공격 라운드 돌파 후 다음 라운드 진입 시 4를 받습니다.

첫 라운드는 핵심 역할 반전을 빠르게 체험하는 온보딩 라운드입니다. 12초 동안 빛나는 추천 칸을 참고해 팝건 1기 또는 블록 벽 2기를 추가하며, 짧아진 6기 웨이브를 막습니다. 강화·실행 취소·다시 실행·설계 저장·되돌리기는 2라운드부터 열리고 이후에는 기존 30초 준비와 전체 설계 기능을 사용합니다.

타워는 최대 2레벨까지 강화할 수 있습니다. 팝건·박격포·관통포의 강화 비용은 각각 2·3·4이며, 2레벨은 공격력 30%와 최대 체력 20%를 얻습니다. 판매하면 기본 건설비와 강화비를 모두 돌려받습니다. 환급 없는 별도 파괴 조작은 제거했으며, 강화 상태는 설계 저장과 다음 라운드에 유지되고 공격 단계에서도 강화된 타워를 그대로 상대합니다.

방어전에서는 타워가 자동으로 적을 공격합니다. 적은 경로 주변의 시설을 파괴하며, 시설이 파괴될 때마다 이동 경로가 다시 계산됩니다. 살아남은 적이 코어에 도달하면 유닛 코스트에 해당하는 누수 피해를 한 번 주고 전장에서 사라집니다. 모든 적을 처치하지 못해도 코어 체력이 남아 있으면 방어에 성공하고, 코어 체력이 0이 되면 방어에 실패합니다.

현재 누수 피해는 공격 편성 가격과 공유하는 코스트 등급을 기준으로 `2코스트: 6`, `3코스트: 12`, `4코스트: 20`입니다. 새로운 가격대의 유닛을 추가할 때 해당 코스트의 누수 피해를 밸런스 설정에 함께 정의합니다. 공격 단계에 진입하면 저장된 방어 설계와 시설 체력이 복원되고 공격 대상 코어도 최대 체력으로 시작합니다.

### 공격 준비

첫 라운드 방어 성공 화면에서 `Enter`를 누르면 역할 반전 연출 후 같은 방어 설계를 상대로 공격 준비를 시작합니다. 이후 라운드는 바로 공격 준비로 전환됩니다.

- `1`: 방패병(출격 포인트 4) — 팝건 포탑에 강함
- `2`: 태엽 군단(출격 포인트 2) — 빠른 고화력 물량 유닛, 태엽 관통포에 강함, 2라운드 해금
- `3`: 고무줄 사수(출격 포인트 3) — 블록 박격포에 강함, 3라운드 해금
- `1` / `2` / `3`: 방패병·태엽 군단·고무줄 사수 선택
- 전장 진입 지점 클릭: 선택한 유닛을 해당 진입로에 추가
- 해당 진입로를 오른쪽 클릭: 마지막 유닛 제거 및 전액 환급
- `X`: 전체 편성을 비우고 전액 환급
- `P`: 현재 라운드 추천 편성으로 초기화
- `Space`: 30초 준비 시간을 일찍 종료하고 공격 시작

지휘관은 별도 설정 없이 항상 2번 중앙 진입로에서 출발합니다. 공격 준비 UI는 일반 유닛의 종류·진입로·출격 순서 결정에만 집중합니다.

출격 포인트는 방어 성과와 직접 연동됩니다. 1~5라운드의 기본분은 기존 고정치보다 3 낮은 21, 24, 27, 30, 33이며, 처치율 보너스 0~5와 남은 코어 체력 보너스 0~3을 더합니다. 평균적인 방어는 기존 예산과 비슷하고 완벽한 방어는 기존보다 최대 5포인트를 더 받습니다. 남은 포인트는 이월하지 않으며 공격 준비가 시작되면 수정 가능한 추천 편성이 자동으로 제공됩니다.

일반 모드의 공격 대상 코어 체력은 라운드별로 650, 650, 1,500, 1,600, 2,900이며, 기준 편성의 목표 돌파시간은 각각 25~40초, 30~50초, 40~60초, 50~70초, 60~85초입니다. 웨이브와 전투 결과는 무작위 보정 없이 같은 설계와 편성에서 재현되도록 구성합니다.

모든 진입로가 하나의 출격 포인트를 공유합니다. 한 진입로에 병력을 집중할 수 있지만 처음 2기만 빠르게 출격하고 초과 병력은 0.9초 간격으로 추가 출격합니다.

같은 4포인트 기준으로 방패병 1기는 체력 125, 태엽 군단 2기는 합산 체력 100입니다. 태엽 군단은 포인트당 공격력이 더 높은 대신 내구도가 낮고, 블록 박격포의 범위 공격에는 여전히 취약하도록 역할을 구분합니다.

### 공격 전투

- `W` / `A` / `S` / `D`: 지휘관을 한 칸씩 직접 이동
- `Q`: 집중 공격 대상 선택 모드
  - 타워를 클릭하면 그 순간 지휘관 반경 3칸 안에 있는 일반 유닛만 해당 타워를 우선 공격
  - 대상 선택 중 청록색 원은 명령 반경, 청록색 테두리가 생긴 유닛은 명령을 받을 부대를 표시
  - 명령 이후 반경에 들어온 유닛은 합류하지 않으며, 타워가 파괴되거나 접근 불가능하면 코어 진격으로 복귀
  - 우클릭 또는 `Esc`: 대상 선택 취소
- `E`: 교란 대상 선택 모드
  - 지휘관 반경 4.2칸 안에서 원하는 타워를 클릭하면 3.2초 동안 공격과 공격 대기시간을 완전히 정지
  - 대상 선택 중 보라색 원과 사각형은 유효 범위와 유효 타워, 붉은 표시는 범위 밖 타워를 표시
  - 클릭 시점에 범위를 다시 검사하며, 범위 밖 타워를 선택해도 스킬을 소비하지 않음
  - 우클릭 또는 `Esc`: 대상 선택 취소

일반 유닛은 자동으로 이동하고 시설과 코어를 공격합니다. 코어를 파괴하면 공격 성공입니다. 지휘관 사망, 90초 제한시간 초과, 대기 병력을 포함한 일반 부대 전멸 중 하나가 발생하면 공격 실패와 함께 현재 도전이 종료됩니다.

공격 성공 화면에서 `Enter`를 누르면 다음 라운드로 진행합니다. 공격 실패 또는 일반 모드 완료 화면에서 `R`을 누르면 1라운드부터 새 도전을 시작합니다.

### 챌린지 모드

일반 모드 5라운드를 모두 돌파하면 부모님의 식사 호출과 함께 아이가 방을 나가는 전환 장면이 표시됩니다. 이 화면에서 `Enter`를 누르면 기존 방어 설계를 유지한 채 `챌린지 1R`로 진입합니다.

- 방어와 공격의 교대 구조, 준비시간과 실패 조건은 일반 모드와 같습니다.
- 웨이브 묶음은 챌린지 1R의 8개부터 증가하며 브라우저 부하를 막기 위해 최대 12개로 제한합니다.
- 적 최대 체력은 챌린지 라운드마다 8, 공격력은 1씩 추가 증가합니다.
- 공격 대상 코어 체력은 2,900에서 챌린지 라운드마다 350씩 증가합니다.
- 성과 계산 전 출격 기준값은 챌린지 1R의 38부터 라운드마다 2씩 증가해 최대 48입니다. 실제 지급량은 `기준값 - 3 + 처치·코어 보너스(0~8)`이므로 최종 상한은 53입니다.
- 다음 챌린지 라운드 진입 시 건설 부품 4를 받고, 기존 설계와 강화 상태를 유지합니다.
- 방어 실패, 지휘관 사망, 일반 부대 전멸 또는 공격 제한시간 초과 시 현재 도전이 종료됩니다.
- HUD와 종료 화면에는 최고 완료 챌린지 라운드와 최근 공격 돌파시간이 표시됩니다.

### 개인 기록

- 일반 모드에서는 5라운드의 총 공격 돌파시간이 가장 짧은 기록을 저장합니다.
- 챌린지에서는 가장 높은 완료 라운드를 우선하고, 같은 라운드는 해당 공격 돌파시간이 더 짧은 기록을 저장합니다.
- 기본 닉네임은 `로컬 플레이어`이며 기록 달성 날짜를 함께 보관합니다.
- 기록은 브라우저 `localStorage`에 저장되어 새로고침하거나 브라우저를 다시 열어도 유지됩니다.
- 튜토리얼 또는 방어 준비 화면에서 `L`을 두 번 누르면 개인 기록을 초기화합니다. 첫 입력 후 3초 안에 다시 눌러야 합니다.
- 전투 중이 아닐 때 `N`으로 온라인 순위표에 표시할 닉네임을 변경합니다.
- 전투 중이 아닐 때 `Tab`으로 온라인 챌린지 상위 10명과 내 순위를 확인합니다.
- 개인 챌린지 신기록은 서버가 연결된 경우에만 자동 제출되며, 서버 오류가 나도 로컬 기록은 유지됩니다.

Supabase 프로젝트 연결 전에는 순위표가 오프라인 상태로 표시됩니다. 서버 연결 방법은 [SUPABASE_LEADERBOARD_SETUP.md](./SUPABASE_LEADERBOARD_SETUP.md)를 참고합니다.

## 아키텍처

게임 규칙을 렌더링 엔진에서 분리하고 의존성 역전 원칙을 적용합니다.

- `application`: 게임 기능을 실행하는 유스케이스
- `config`: 게임 전역 설정과 밸런스 데이터
- `domain`: 격자, 시설, 방어 설계와 경로 탐색을 포함한 순수 게임 규칙
- `ports`: 외부 기술에 의존하지 않는 인터페이스
- `infrastructure`: Phaser 및 저장소 구현
- `presentation`: 장면과 사용자 인터페이스

자세한 게임 규칙은 [GAME_DESIGN_DOCUMENT.md](./GAME_DESIGN_DOCUMENT.md)를 참고합니다.
