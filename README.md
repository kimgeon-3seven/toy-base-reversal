# Toy Base Reversal

장난감 요새를 직접 설계해 적의 웨이브를 막고, 공격 부대를 편성해 자신이 만든 요새를 돌파하는 PC 브라우저 전략 게임입니다.

## 기술 구성

- Phaser 3
- TypeScript
- Vite
- Vitest
- ESLint
- pnpm

## 로컬 실행

```bash
pnpm install
pnpm dev
```

## 품질 검사

```bash
pnpm check
```

`check`는 린트, 단위 테스트, 프로덕션 빌드를 차례로 실행합니다.

## 현재 구현된 4단계 프로토타입 조작

일반 모드는 총 5라운드이며, 각 라운드는 `방어 준비 → 방어 전투 → 공격 준비 → 공격 전투` 순서로 진행됩니다. 공격에 성공하면 돌파시간이 기록되고 이전 방어 설계를 유지한 채 다음 라운드로 넘어갑니다. 5라운드를 모두 완료하면 챌린지 모드 진입 예고가 표시됩니다.

### 방어 준비 및 전투

- `1`: 공격 타워 배치 모드
- `2`: 장애물 배치 모드
- 왼쪽 클릭: 시설 배치 또는 선택, 선택 후 빈 칸 클릭 시 무료 재배치
- 오른쪽 클릭: 시설 판매
- `Delete`: 선택 시설 파괴 및 경로 재계산
- `S`: 현재 방어 설계 저장
- `R`: 저장된 방어 설계와 시설 체력 복원
- `Space`: 30초 준비 시간을 일찍 종료하고 방어전 시작

진입점 또는 코어 보호 구역에는 시설을 지을 수 없으며, 세 진입점 중 하나라도 코어까지 갈 수 없게 만드는 배치는 거부됩니다.

방어전에서는 타워가 자동으로 적을 공격합니다. 적은 경로 주변의 시설을 파괴하고 코어에 도달하면 코어를 공격하며, 시설이 파괴될 때마다 이동 경로가 다시 계산됩니다. 웨이브를 전멸시키면 방어 성공, 코어 체력이 0이 되면 방어 실패입니다.

### 공격 준비

방어 성공 화면에서 `Enter`를 누르면 같은 방어 설계를 상대로 공격 준비를 시작합니다.

- `1` / `2`: 탱커 또는 원거리 유닛 선택
- `Q` / `W` / `E`: 선택한 유닛을 상단·중단·하단 진입로에 추가
- `Backspace`: 마지막으로 편성한 유닛 제거
- `C`: 지휘관 시작 진입로 변경
- `Space`: 30초 준비 시간을 일찍 종료하고 공격 시작

모든 진입로가 하나의 편성 예산을 공유하며, 각 진입로에는 배치 인원 제한이 있습니다.

### 공격 전투

- `W` / `A` / `S` / `D`: 지휘관을 한 칸씩 직접 이동
- `Q`: 일정 시간 일반 유닛을 지휘관 주변으로 집결
- `E`: 사거리 안의 가장 가까운 타워를 일시 무력화

일반 유닛은 자동으로 이동하고 시설과 코어를 공격합니다. 코어를 파괴하면 공격 성공이며, 지휘관이 쓰러지거나 제한 시간이 끝나면 공격 실패입니다.

공격 성공 화면에서 `Enter`를 누르면 다음 라운드로 진행합니다. 공격 실패 시 `R`을 누르면 현재 라운드의 공격 준비부터 다시 시도합니다. 일반 모드 완료 화면에서는 `R`로 1라운드부터 다시 시작할 수 있습니다.

## 아키텍처

게임 규칙을 렌더링 엔진에서 분리하고 의존성 역전 원칙을 적용합니다.

- `application`: 게임 기능을 실행하는 유스케이스
- `config`: 게임 전역 설정과 밸런스 데이터
- `domain`: 격자, 시설, 방어 설계와 경로 탐색을 포함한 순수 게임 규칙
- `ports`: 외부 기술에 의존하지 않는 인터페이스
- `infrastructure`: Phaser 및 저장소 구현
- `presentation`: 장면과 사용자 인터페이스

자세한 게임 규칙은 [GAME_DESIGN_DOCUMENT.md](./GAME_DESIGN_DOCUMENT.md)를 참고합니다.
